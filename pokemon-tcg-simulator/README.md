# TCG Pack Simulator

A static, GitHub Pages-ready card pack opening simulator. No backend is required.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Save data
Progress is stored in the browser using `localStorage`. It is device/browser-specific and is not synced online.

## Artwork
The starter uses original placeholder creature names/icons rather than Pokémon card artwork. You can replace the card data and images for your own private copy.
